# knowledge/rules — always-on rules

Short, agent-agnostic rules that apply to **every** task in this repository, regardless of which AI agent or IDE is being used (this is the portable replacement for `.cursor/rules` / CLAUDE.md-only rules).

Load every `*.md` file in this directory (except this README) at task start — see the "Before you start" section of [/AGENTS.md](/AGENTS.md).

Add a new file here when a constraint should apply to all future tasks. Keep each file focused on one rule.
